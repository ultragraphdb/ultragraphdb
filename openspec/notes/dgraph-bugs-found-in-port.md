# Dgraph bugs found while porting

The port reproduces Dgraph's behaviour, bugs included, unless a spec declares a behaviour change; step 3 of the plan
(`dgraph-port-overview.md`) fixes known bugs on the tested Rust code. This ledger holds what the port found, with the
evidence, so step 3 starts from it. Paths are in the Dgraph fork at commit `9fbf35614` (v25.5.0 plus six commits). The stage-1 remedies are the OpenSpec change
`fix-ported-dgraph-defects`, archived on 2026-10-23 with its requirements in `openspec/specs/`; the remedies that need
later stages' code are tasks of those stage changes. "The port" states what the port does today; "Status" says whether
that is the remedied behaviour (Fixed) or which stage and task brings it (Open).
