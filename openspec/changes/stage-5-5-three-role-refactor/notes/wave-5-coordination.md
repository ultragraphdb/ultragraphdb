# Wave 5 coordination

Five agents run groups 6, 6b and 8 in parallel from `cabae5ec`: metadata (the `ultragraphdb_cluster_metadata` crate),
catalog (group 6's catalog side), placement model (6b, Lean), wire (group 8's `protocol_wire`) and transport (group 8's
carriers and TLS). An agent appends one line here when an API others call compiles, and one when its part is done, so
the agents building on it know when to compile against it:

- `SURFACE READY: <crate> — <one-line summary of the public API others call>`
- `DONE: <part>`
- `NOTE (<part>): <a change another part must know>`

Agents waiting on a surface poll this file (`until grep -q 'SURFACE READY: <crate>' …`) and write their tests meanwhile.
