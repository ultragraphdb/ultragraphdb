# Group 4 coordination

Four agents run group 4 in parallel. An agent appends one line here when its API surface compiles, and one when its
crates are done, so the agents that build on it know when to compile against it:

- `SURFACE READY: <crate> — <one-line summary of the public API others call>`
- `DONE: <crate>`

Agents waiting on a crate poll this file (for example `until grep -q 'SURFACE READY: ultragraphdb_protocol_wire' …`)
and write their tests meanwhile.
